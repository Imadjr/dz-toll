# License-plate detection model

`best.pt` is the model loaded by `backend/smart_toll_system.py`.

Verified archive metadata identifies a YOLOv8n base model with one class named `license_plate`. The repository does not contain the training dataset, training configuration, or evaluation logs, so no accuracy or dataset-size claim is made here.

The runtime path can be overridden with `MODEL_PATH` in `backend/.env`.
